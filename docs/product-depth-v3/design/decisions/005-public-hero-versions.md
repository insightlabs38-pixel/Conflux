# D-005 · Public hero and project versions
- Hero styles: none · **compact (default)** · standard · immersive (opt-in, Advanced). Compact 160–240px desktop, ≤120px mobile; typographic lockup fallback when no art.
- Organizer themes override `--pub-accent`/`--pub-bg` only; save is blocked if contrast <4.5:1 for text or <3:1 for UI. Text over art always sits on a solid base colour.
- Project pages are permanent URLs. Default view = Living; "As judged · rN" is a linked immutable snapshot with provenance (renderer version, media digests, source commit). Banner states which version is shown.
- Results page shows winners + as-judged links; scores/judge comments are not public.
