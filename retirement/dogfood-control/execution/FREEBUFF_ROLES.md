# Freebuff Lane

One top-level serial bulk task lane using GLM 5.3 Flash by default. Provider-built-in helper agents may assist internally where available in the pinned working build. Custom user-defined agents are disabled. No extra top-level Freebuff session, queue scheduling, other-session control or unauthorized Freebuck spend.

Consume one bulk-eligible ready task at a time. Canonical state is owned by conflux-control. The owner may route work elsewhere when Freebuff is occupied or stronger reasoning is needed.
