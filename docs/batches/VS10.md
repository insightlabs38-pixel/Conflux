# VS10 — Migration preview/diff

## Result
Canonical v1 archive imports can be previewed before creating an event. Unsupported versions return a clear error because no migration path is defined.

## Changes
- Added an organizer-only preview API that runs the canonical importer in a rolled-back transaction.
- Reports event-field changes, section counts, ignored sections, and empty migration/deprecation lists for v1.
- Added OpenAPI and SDK definitions; documented the v1 boundary and slug race.

## Verification
- Archive, template, and CSV integration tests: 27 passed.
- Django system and migration checks: passed; no model changes.
- OpenAPI validation, SDK generation, Ruff, and diff check: passed.

## Limitations
- Preview does not reserve the requested slug; a concurrent import can claim it.
- Only v1 archives are supported. No migration or deprecation rules exist yet.
- No recorded-surface manifest exists for this API-only change; footage unaffected.
