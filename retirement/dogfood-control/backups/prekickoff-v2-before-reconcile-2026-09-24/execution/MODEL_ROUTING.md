# Model Routing

## Claude Code / Sonnet 5
Use first for: identity/authorization architecture, Stage/Project/Submission invariants, policy semantics, submission finalization/deadline concurrency, normalization-aware assignment, normalization math/proof, security architecture, weird performance pathology, major Core gates and P0/P1 unexplained bugs.

Batch related work to amortize context. The campaign prompt should reconstruct state from a small authoritative set, use targeted reading, execute one coherent batch, verify, update handoff and stop.

## Codex CLI
GPT-6 Sol is the default serious implementation model unless measured subscription accounting suggests another route. Use for large vertical features, cross-stack subsystems, API/portability/operations, integration and ordinary difficult corrections. Luna is useful for inexpensive secondary implementation/review/overflow where GLM is not the better free lane.

## Freebuff / GLM 5.3 Flash
Default for parallel straightforward implementation, frontend surfaces, validators, fixtures, docs, polish, ordinary endpoints, routine corrections and especially verification breadth.

## Escalation
Freebuff never autonomously invokes paid/scarce OpenAI/Anthropic models. It writes an escalation packet and raises `ATTENTION`; human assigns Claude/Codex. Related escalations may be batched into one frontier invocation.
