# S11 — Reminder/scheduling engine

## Result
Complete. Organizers can schedule submission deadline, judging, and voting reminders for a live audience and cancel pending reminders.

## Changes
- A database reminder record and 30-second Celery beat dispatcher deliver due messages to the in-app inbox.
- Dispatch resolves recipients at send time and commits the message, recipients, audit, and sent marker together; repeated polls do not duplicate delivery.
- Invalidated audiences retry after 10 minutes; revoked organizers cannot send. The communications panel shows scheduling, status, and cancellation.
- OpenAPI and migration are updated. Footage impact: unaffected; no recorded-surface or scene manifest exists.

## Verification
- Reminder, communications, audience, and lock regression suites: 16 passed.
- Repository Python suite: 540 passed, 8 skipped; Django/migration/OpenAPI and scoped Ruff checks: clean.
- Web lint/build and 66 tests; embed build and 7 tests: passed.

## Limitations
- Reminder times are chosen explicitly because judging has no deadline field; automated sends use the in-app channel, while organizer messages still support best-effort email.
