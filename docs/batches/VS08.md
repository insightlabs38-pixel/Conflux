# VS08 — Rubric laboratory

## Result
Complete. Organizers can inspect one published rubric version's historical ballots for score variance, scale use, criterion dominance, and ranking changes under alternate criterion weights.

## Changes
- Added read-only `POST .../rubric-lab/` with bounded weight multipliers and optional historical rubric-version selection.
- Reports per-criterion response coverage, mean, population variance, observed scale span, endpoint use, weight/spread shares, and rank shifts.
- Uses the existing judge-effect estimator for each scenario without creating a normalization run. OpenAPI/SDKs updated. Footage impact: unaffected; no recorded-surface or scene manifest exists.

## Verification
- Scoped normalization/evaluation suite: 62 passed, including historical-version isolation, missing responses, invalid factors, and permission cases.
- OpenAPI/SDK, migration/system, Ruff lint/format checks passed.

## Limitations
- Diagnostics use submitted ballots from one frozen rubric version; they do not combine scores from different versions or predict future judges.
- The laboratory is API/SDK-only in this batch.
