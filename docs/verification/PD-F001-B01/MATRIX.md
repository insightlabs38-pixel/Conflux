## Cross-cutting (T90)

- `test_every_read_is_organizer_or_admin_only_and_tenant_scoped` (configuration, workflow, readiness): organizer and admin 200; judge, participant, other-workspace organizer 403; anonymous denied; other workspace named in the URL 404.
- Concurrency and idempotency: the slice mutates shared rows in two places only, creation (address race, above) and module settings (idempotent, above). Everything else it adds is read-only or goes through existing endpoints.
- Migration: additive tables only (`EventProfile`, `EventModuleSetting`); no backfill; events without a profile behave as before (above, and the T00 census probe).
