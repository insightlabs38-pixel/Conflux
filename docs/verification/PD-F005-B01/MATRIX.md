## Cross-cutting checks

- Authorization and visibility: no endpoint changed. The switcher, search and inbox read endpoints that already authorize; a judge sends no record query (tested); a participant is offered no organizer place. Audit: nothing in the shell writes state; mark-read, sign-out and every future mutating command use existing endpoints.
- States: loading, empty, error with retry, permission, long list and many unread are shown in the switcher, panel, search and palette (component tests) and exercised in the browser where the data allows. Mobile: every overlay is tested at 390 inside the viewport.
- Migration and compatibility: no persisted server value changed; legacy URLs still redirect (routing spec); device keys are new and versioned (`conflux:v1:`).
- Regressions found and fixed by this verification: the realtime spec showed two subscribers doubling inbox reads (fixed: only the bell subscribes, with a test); the notifications spec became ambiguous (its finder scoped to the page); the visual ratchets named the new floating layers (switcher, notification panel, phone sheet) and a grouped selector that hid `.cx-account__panel` from the parser (selectors restored, new layers added to the allowlist with their tokens).
