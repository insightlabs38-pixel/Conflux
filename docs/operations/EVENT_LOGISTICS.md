# Event logistics utilities (PVS16)

All build on existing primitives (onsite `Location`s and project placements, public-event visibility, signed QR passes from PVS03).

| Feature                     | Route                                                        | Notes                                                                                                                                                                                                              |
| --------------------------- | ------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Agenda sessions (organizer) | `…/events/{e}/agenda/`, `…/agenda/{id}/`                     | title, times (`ends_at > starts_at`), optional room/track of the **same event**, speakers, `stream_url` (plain https only), `is_public`. Audited; unknown fields rejected.                                         |
| Public agenda               | `/e/{e}/agenda/` (page), `/api/v1/events/{e}/agenda/` (JSON) | Private sessions never appear.                                                                                                                                                                                     |
| Calendar feed               | `/e/{e}/agenda.ics`                                          | RFC 5545: CRLF, 75-octet folding, escaped text (a title cannot inject calendar lines), stable `UID`s. Subscribe from any calendar app.                                                                             |
| Stream embeds               | on the agenda page / `embed_url` in JSON                     | Only YouTube (privacy-enhanced domain), Vimeo, and hosts in `CONFLUX_EMBED_HOSTS` are framed (sandboxed, no referrer, lazy); every other stream is a plain link. Video IDs are validated, lookalike hosts refused. |
| Event state                 | `/api/v1/events/{e}/state/`                                  | `phase` (`upcoming`/`live`/`ended`), live and next sessions, public project count; CORS-open for embedding on other sites.                                                                                         |
| Status badge                | `/e/{e}/badge.svg`                                           | Small escaped SVG for READMEs and sponsor pages.                                                                                                                                                                   |
| Expo map                    | `/e/{e}/map/`                                                | Printable table of tables/booths by room with their **publicly visible** projects (finalized and gallery-released).                                                                                                |
| Attendee QR pass            | existing `my-pass/qr/` (PVS03)                               | unchanged.                                                                                                                                                                                                         |

Public event surfaces are deliberately served with no-cache headers (scheduled publication windows must flip exactly on time), so feeds and state are always live. Unpublished events and unreleased archives are 404 for every route above. Agenda sessions are part of the final archive.
