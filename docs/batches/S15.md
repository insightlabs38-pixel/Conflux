# S15 — Award conflict solver

## Result
Complete. Organizers can preview valid award allocations before selecting winners.

## Changes
- Read-only proposals keep existing winners fixed and honor event, track, submission, capacity, stacking, and conflict group rules.
- Published evaluation and community rankings provide candidates without requiring an override; unavailable results report a blocker.
- The solver maximizes filled positions within a bounded deterministic search and marks responses when the search limit is reached.
- The Awards screen shows proposals and lets an organizer prepare a suggested winner for explicit selection. Footage impact: unaffected; no recorded-surface or scene manifest exists.

## Verification
- Award and prize integration suites: 17 tests passed.
- Web Vitest: 33 files, 69 tests passed; TypeScript check passed.
- OpenAPI schema regenerated and validated.

## Limitations
- `search_limited` means maximum coverage was not proven; proposals remain constraint-valid. Overrides and unpublished source results require manual selection.
