# S07 — Advanced Submission CI
## Result
Complete for the checks the product actually models: real, explicitly-triggered reachability plus GitHub license/latest-commit evidence for `repository`/`live_url` artifacts, additive to (never replacing) the existing network-free structural validator.
## Changes
- `artifacts/reachability.py`: `pinned_get` (SSRF-safe GET reusing `integrations.webhooks.validate_destination`'s DNS-resolve-and-pin pattern exactly) and `github_evidence` (best-effort `api.github.com` license + latest-commit lookup for a public GitHub repo, degrading honestly when unavailable rather than guessing).
- `artifacts/validators.py::run_submission_ci`/`inspect_submission_ci`: a new, separate check path recording a `submission_ci`-validator `ArtifactValidation` row. Deliberately **not** wired into `inspect_artifact`/`validate_artifact` (the synchronous, network-free structural gate an existing test locks in) and never mutates `artifact.status` — a flaky demo link shouldn't destroy submission evidence.
- New `POST .../artifacts/<id>/check-evidence/` (organizer/owner-triggered, same visibility rule as the existing validate endpoint), restricted to `repository`/`live_url` kinds; `artifact_payload` gained an additive `ci_evidence` list, leaving the existing `validation` field's meaning untouched.
## Verification
- New `tests/integration/test_artifact_reachability.py` (4, pure): connection pinning proven the same way `test_webhooks.py` proves it, GitHub evidence success/degradation, repo-path parsing.
- New `tests/integration/test_artifact_ci_api.py` (5): evidence recorded without touching status, non-200 reported as a warning, GitHub lookup skipped for non-GitHub links, a private/malformed URL is blocked via the reused SSRF guard, non-link kinds are rejected.
- Full suite: 504 passed, 8 skipped (was 495/8), including the pre-existing `..._without_network_fetch` test unchanged; `ruff format`/`check`, `manage.py check`, `makemigrations --check` (no migration needed), OpenAPI artifact check, `pnpm build`/`test` all clean.
## Limitations
- "Sponsor evidence checks" (from the stretch goal's title) has no backing domain concept to extend -- no sponsor/track-requirement model exists anywhere in the product, and inventing one would be new identity semantics the frozen architecture doesn't call for; left undone rather than fabricated.
- GitHub-only for commit/license evidence; other forges get reachability only.
