## Cross-cutting (T90)

- Reading never writes: every consequences action and the generated configuration leave audit, domain-event, event, stage, link, track, prize, profile and module rows unchanged.
- Migration: no new tables; both endpoints are computed from existing rows and the registry, so there is nothing to backfill.
- Concurrency: nothing new is stored; a race between preview and operation is resolved by the operation's own validation.
