# VS11 — Signed portable event archive

## Result
Organizers can export and import a signed canonical event archive. Verification checks the signature and all checksums before import.

## Changes
- Added a versioned Ed25519 envelope with a whole-archive digest and checksums for every top-level key.
- Added signed export/import routes that retain canonical import validation and audit behavior.
- Documented the portable format and source-key pinning requirement; updated OpenAPI and SDKs.

## Verification
- Archive, template, and verifiable-record integration tests: 47 passed.
- Django system and migration checks: passed; no model changes.
- OpenAPI validation, SDK generation, Ruff, and diff check: passed.

## Limitations
- Embedded-key verification proves integrity; source identity requires an externally trusted key.
- Signing key rotation and revocation are not supported by envelope v1.
- No recorded-surface manifest exists for this API-only change; footage unaffected.
