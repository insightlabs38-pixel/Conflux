# VS05 — Judge dropout simulation

## Result
Complete. Organizers can preview assignment coverage and replacement work for up to ten judge dropout scenarios before rebalancing.

## Changes
- Extracted rebalance's pairing calculation so simulation and activation use the same conflict, expertise, submitted-ballot, and connectivity rules.
- Added read-only `POST .../assignments/dropout-simulation/` for one or more pool judges per scenario; it reports coverage gaps, pending work removed, assignments added, and assignment evidence.
- Updated OpenAPI and generated TypeScript/Python SDKs. Footage impact: unaffected; this adds no recorded surface.

## Verification
- Scoped evaluation suite: 47 passed, including preview/rebalance parity, multi-judge gaps, and invalid scope/permission cases.
- OpenAPI/SDK checks, migration/system checks, Ruff lint/format: passed.

## Limitations
- Scenarios use the current active assignment and submitted ballots; a later change to either requires a fresh preview.
- This batch adds API/SDK access without an organizer UI.
