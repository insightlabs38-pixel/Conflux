# VS13 — Reusable judge directory

## Result
Organizers can reuse workspace judges across event pools through invitations that judges accept or decline.

## Changes
- Added an organizer-only workspace directory and event-pool invitations with one-time responses and revocation.
- Acceptance creates only an event-pool membership; declined, revoked, and pending invitations grant no pool access.
- Pool-bound plans now reject ballots and drafts from judges outside their pool, including non-prize plans.
- Added organizer and judge controls, audit entries, API documentation, OpenAPI, and generated SDKs.

## Verification
- Judge-directory and affected judging integration suites: 71 passed.
- Full web suite: 88 passed; production build passed.
- Django migration/system checks, OpenAPI/SDK checks, Ruff, and diff check: passed.

## Limitations
- Direct organizer pool membership and plans without a pool retain their existing eligibility behavior; see the API guide.
- No recorded-surface or scene manifest exists; footage impact: unaffected.
