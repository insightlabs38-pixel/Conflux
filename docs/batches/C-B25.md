# C-B25 — Operations center, communications and launch checklist
## Result
Complete. Organizers get a live cross-domain blocker summary, a dynamic-audience
messaging tool with an in-app inbox, and an event launch checklist.
## Changes
- New `communications` app: `operations.py` aggregates unteamed participants,
  blocked teams, submission preflight, judging progress, stage occupancy,
  publication and unresolved abuse signals (OPS-001).
- `audiences.py`: computed (never saved) audience kinds (roles, unteamed,
  blocked teams, track, incomplete judges); `Message`/`MessageRecipient` give
  every send a durable in-app inbox plus best-effort email, the repo's first
  real `django.core.mail` use — console backend by default, SMTP via env
  (OPS-002/003).
- `checklist.py`: launch rules for dates, unpublished forms, contradictory
  gate/voting windows, missing rubrics, unstaffed pools, an empty public
  page (OPS-004).
- Frontend `OperationsCenter`/`CommunicationsPanel`/shared `Inbox`, mounted
  into the organizer dashboard, team workspace and judge workspace (OPS-005).
## Verification
- New tests → 12 passed; full backend suite → 405 passed, 3 skipped.
  Ruff/Django check/migrations/OpenAPI clean; `pnpm test`/`build` clean.
## Limitations
- `make format-check` already fails on baseline `main` (pre-existing, unrelated).
