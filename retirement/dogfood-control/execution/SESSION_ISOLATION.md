# Session Isolation

Sessions operate only on explicitly leased branches/worktrees. No session may control another process, type into another tmux pane, inspect private transcripts or use another lane's authentication. Owner controls local Claude directly.

Freebuff has one top-level serial session. Provider-built-in helpers may run inside it. Custom user-defined agents are disabled due current provider 403. Luna capacity begins at one.

Coordinate through Git, controller leases, receipts, ATTENTION and escalation packets. Queue and ownership mutations go through conflux-control or explicit human/integration recovery.
