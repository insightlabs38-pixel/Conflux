Product Depth v3 · foundation design pass · second pass

Conflux v3 design system and reference surfaces

One neutral, compact, table-first language for participant, judge, organizer, onsite and public surfaces. Revision r2 · 45 artboards · 14 reference groups. r1 is preserved under exports/r1.

Converged decisions

Direction
“Ledger” — light neutral canvas, hairline structure, one blue accent used only for action, selection and focus.
Type
IBM Plex Sans 14/13/12 for UI, Plex Mono for IDs and code, Source Serif 4 for public long-form reading only.
Density
Three modes: comfortable 44 · standard 36 · dense 28 px rows. Standard is default; dense is per-user.
Shape
Radii 3 / 5 / 8. Borders carry hierarchy; shadow only on floating layers.
Status
Icon + word + tint. Colour is never the only signal. Plain text status in tables; tinted tags only for summaries.
Shell
44px top bar, 216px rail (collapses to 52px), right inspector that keeps list position. Participant/judge use a top bar only.
Hero
Public: none / compact (default, 160–240px) / standard. Operator surfaces: no hero.

Final quality tests

Reads as mature software. Every screen is one hairline surface family with a single accent; there are no gradient washes, coloured icon tiles or nested cards.
5,000-person event. A saved-view grid, keyboard cursor, range select, frozen-snapshot bulk plans and async progress carry organizer work; the overview is a queue strip, not KPI cards.
Weekend-hackathon base. Nav shows 6 groups by default; Advanced groups stay collapsed; setup is a 5-step checklist with defaults, not a settings wall.
