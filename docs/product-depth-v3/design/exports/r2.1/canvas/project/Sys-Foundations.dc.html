Icon policy

1.75–2px stroke, 16px default (20 for empty states, 12–14 in tags). currentColor only.
  • Use for recognition of repeated things (nav, status, tool buttons, file kinds). Always beside text unless the control has an aria-label and a tooltip.
  • Never in a tinted square beside a heading; never as decoration in empty states beyond one 20px glyph.
  • Status glyph vocabulary (shape differs, not just colour): ✓ circle = complete · △ = needs action · ✕ circle = blocked/failed · ◔ = in progress · ▸ dashed circle = not started · = information.
  • Library: Lucide-compatible set; mask-rendered so it inherits text colour and forced-colors mode.
